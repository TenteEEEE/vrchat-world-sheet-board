更新ボタンの待ち時間を短くし、ボタンと状態ランプの配色を読みやすく見直しました。

- **更新** ボタンは、押してから 5 秒たつと再び押せます（従来は 30 秒）。VRChat の String Loading の上限（5 秒に 1 回）と同じ間隔です。読み込み中は押せません。
- 更新ボタンの文字は取得中も「更新」のままです。押せない間はグレーの配色で示します。取得中であることは、これまでどおり状態行の「・更新中…」とランプの点滅で表示します。
- 更新ボタンと状態ランプの既定色をライト・ダークそれぞれに合わせ、文字と背景のコントラストを高めました（ボタンの文字は 4.5:1 以上）。シートで指定した文字色・背景色はそのまま表示します。
- Display に **更新ボタンの色**・**更新ボタンの文字色**・**押せない間のボタン色**・**押せない間の文字色** を追加しました。透明（α 0）のままならテーマの既定色を使います。

### 更新時の注意

Display の「更新中のボタンの文言」（`refreshBusyText`）は廃止しました。設定していた場合は無視されます。Source の **手動更新の待機時間** を Inspector で変更している掲示板は、その値がそのまま使われます。Apps Script（`SheetBoard.gs`）の更新は不要です。
