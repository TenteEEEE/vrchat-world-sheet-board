「掲示板をシーンに置く」で置かれる掲示板の位置を変えました。板の中心はワールド原点から高さ 1.3 m（身長 1.3 m 前後のアバターの目線）、向きは固定です。水平位置はこれまでどおりシーンビューで見ている場所です。

データ元の閲覧権限の選択肢を PermissionController の言葉に合わせ、「全員／管理者と協力者／管理者のみ」にしました（設定値はそのままです）。

### インストール

VCC の一覧 [TenteEEEE VPM Repository](https://tenteeeee.github.io/vpm-repos/index.json) から **Utsushi 0.6.1** を追加してください。手動で導入する場合は、添付の `.unitypackage` を使えます。

詳しい手順は [日本語 README](https://github.com/TenteEEEE/vrchat-world-utsushi/blob/main/README.ja.md) を参照してください。
