大きな表でも途中で表示が切れないよう、範囲数・行列数・描画プールの設定上限を撤廃しました。ワールド内の標準文言は、訪問者の VRChat 言語に合わせて日本語・英語に切り替わります。

- Display は必要な分だけ描画オブジェクトを増やします。折り返し・結合セル・ドロップダウンの多い表に対応し、空セルがオーバーレイを使い切る問題を修正しました。
- 長い列の文字を行ブロックに分けて描画します。1 セルは最大 4,000 文字まで表示し、超過分には「…」を表示します。
- 手動で非表示にした行列と、フィルタで除外された行を公開対象から外します。
- Apps Script の公開処理は 4 分 30 秒・JSON 10 MB の技術上限を確認し、超過時は既存の公開データを保ったまま失敗を通知します。大きな表や iPhone での読み込みに関する注意も表示します。
- Source の URL 未設定・未適用をビルド時に検出し、Source のない Display には警告します。

### 更新時の注意

- **Google スプレッドシート側の `SheetBoard.gs` も最新版に差し替えてください。** 公開先 URL の作り直しは不要です。
- Display の `maxRows`・`maxCols`・`maxOverlays` を削除しました。大きな表は描画負荷が増えるため、必要に応じて公開範囲を調整してください。
- Source と Display の表示言語は `Auto` / `Japanese` / `English` から選べます。空欄または従来の日本語既定値の文言フィールドには、選択した言語の既定文言を使います。独自の文言はそのまま表示します。

### インストール

VCC の一覧 [TenteEEEE VPM Repository](https://tenteeeee.github.io/vpm-repos/index.json) から **Sheet Board 0.4.0** を追加・更新してください。手動で導入する場合は、添付の `.unitypackage` を使えます。

動作環境は **Unity 2022.3 / VRChat Worlds SDK 3.10 以降**です。詳しい手順は [日本語 README](https://github.com/TenteEEEE/vrchat-world-sheet-board/blob/main/README.ja.md) を参照してください。

検証済み: Node のテスト 78 件、Unity 2022.3.22f1 での UdonSharp コンパイル・prefab 再生成・配線・権限・日英文言の検査、明暗テーマを含む 20 枚の描画出力。チップ 101 個、大きな表、折り返し・結合、文字欠落・位置ずれの検査と代表画像の目視確認を実施しました。VRChat 実機での確認は未実施です。
