ドロップダウンの多い範囲で、途中からチップが表示されなくなる不具合を直しました。

- チップは 64 個までしか描けなかったため、それより後ろのドロップダウンのセルが、チップも ▼ もないただの文字になっていました。表示できるセル数（**最大行数 × 最大列数**、既定 40 × 12）まで、すべてのチップを描くようにしました。
- チップは必要になった分だけ作るので、チップの少ない範囲で負荷が増えることはありません。
- Display の **チップの上限**（`maxChips`）は不要になったので削除しました。

### 更新時の注意

- Apps Script（`SheetBoard.gs`）の差し替えは不要です。
- シーンに置いた掲示板は、パッケージを更新すればそのまま直ります。`maxChips` を変更していた場合も、その値は使われなくなるだけで、作業は要りません。

### インストール

VCC の一覧 `https://tenteeeee.github.io/vpm-repos/index.json` から **Sheet Board 0.3.1** を追加・更新してください。手動で導入する場合は、添付の `.unitypackage` を使えます。

動作環境は Unity 2022.3 / VRChat Worlds SDK 3.8 以降です。詳しい手順は [日本語 README](https://github.com/TenteEEEE/vrchat-world-sheet-board/blob/main/README.ja.md) を参照してください。

検証済みの項目: Node のテスト 69 件、Unity 2022.3.22f1 での UdonSharp コンパイル、prefab の再生成と配線、チップ 101 個の範囲を含むサンプルの描画とチップ数の検査（修正前のコードで不足を検出できることも確認）、配布アーカイブの内容とチェックサム。VRChat 実機での確認は未実施です。
