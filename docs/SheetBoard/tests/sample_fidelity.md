# fidelity fixture

`Assets/SheetBoardDev/Samples/sample_fidelity.json` は、Unity のプレビュー描画を確認するための架空の資材・作業計画データです。

カバーする描画ケース:

- `event`: 結合セルと空の被覆セル、空行、書式あり／なし、文字色と背景色、行高・列幅・文字サイズの差、日本語と ASCII、タイトルなし・ヘッダーなし。
- `wraptest`: 長い日本語のはみ出し、右隣の空セル、改行と折り返し、左・中央・右揃え、4 種類のスタイルビット、数値表示文字列。
- `fitcase`: 11 × 6、行高 21 px。C 列と E 列は全行空の細いスペーサー。長い日本語の見出しと最終行の文字で幅調整を確認し、タイトルなし・ヘッダーありを維持。
- `chips`: 明示色と自動配色、空セルの矢印、行列をまたぐ同一ラベル、空白正規化される `種子`、ダッシュ状の空ラベル、日本語・ASCII・全角文字、太字と通常文字、5 種類の文字サイズ、異なる行高。

`sample_fidelity.test.cjs` はデータ全体のスナップショットや描画処理のテストではなく、JSON の形とこれらのフィクスチャ上のカバー条件を検査します。
